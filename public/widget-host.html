Widget host test

This page stands in for a third-party site that embeds Baza NISR with one script tag. Open the floating button, ask a question, and check that the answer, period and source match the main app.

The tag, copied from the Integrate view:

<script src="widget.js" data-language="rw"></script>

Inside the panel the requests come from the Baza iframe, so they are same-origin and need no cross-origin allow-list.
