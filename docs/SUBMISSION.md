## Project description

Baza NISR helps citizens, students and planners find and understand Rwanda's official statistics in Kinyarwanda, English and French. It connects each supported answer to a publication, page, table, reference period and measured population. The collection includes national, provincial and district poverty estimates and selected annual labour-market indicators. Comparisons retain methodology labels and uncertainty; unsupported periods and cross-tabulations are refused rather than estimated.

The public application needs no account or paid model API. Its deterministic evidence engine runs in the browser on GitHub Pages. A website widget provides a practical integration path. The same source includes server builds and a documented API for institutional hosting; those API endpoints and live catalogue search are not deployed on GitHub Pages. Optional browser-local AI can explain an existing answer on compatible devices, and is clearly marked experimental.

The project fits Open Innovation through access to evidence for national planning, with poverty reduction as its demonstration use case. It is a student prototype, not an official NISR service. Translation review and institutional operational testing remain future work.

## Before submitting the form

1. Confirm the latest GitHub verification and Pages deployment runs are successful and correspond to the release commit.
2. Open the app without signing in; run the short demonstration in [JUDGING.md](JUDGING.md).
3. Use the team's registered track. If it is Poverty Reduction, frame the problem around poverty evidence; if Open Innovation, frame it around access to official statistics. Do not change the registered track based on this document alone.
4. Read the AI disclosure and competition IP conditions. The team must personally confirm originality, eligibility and that the work has not been submitted elsewhere; repository tests cannot establish those declarations.
5. Submit the repository URL, app URL and documentation link through the official entry form. Preparing and publishing the project does not submit that form.

The [official competition page](https://statistics.gov.rw/about/hackathon/2026-hackathon-competition) lists the deadline as 30 October 2026, 11:59 PM; the page does not state a timezone.
